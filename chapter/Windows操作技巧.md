# Windows 操作技巧



## 图形界面



##### 切换窗口

`Alt` + `Tab`

两次 `Tab` 可以切换到下下个窗口



##### 关闭当前窗口

`Alt` + `F4`



##### 调整缩放比例

`Ctrl` + `Shift` + `+` / `-`



### 常用操作

#### 任务管理器

##### 打开方法

1. 桌面底部栏右键 - 任务管理器
2. `Ctrl` + `Shift` + `Esc`







### 常见问题

#### F1、F2、F3 等按键效果与预期不同

解决：

`Fn` + `Esc` 打开 Fn 锁，此时在屏幕上出现 `FnLock` 图案。

## 命令行



### 常用操作



#### 停止运行在指定端口的进程

以 5173 端口为例：

```cmd
for /f "tokens=5" %a in ('netstat -ano ^| findstr :5173') do taskkill /PID %a /F
```
